- **যেকোনো সময় যেকোনো ফাইলের লিঙ্ক কপি**: আপলোড করার সাথে সাথেই নয়, ফাইল ম্যানেজারের গ্রিড ভিউ বা লিস্ট ভিউতে থাকা **যেকোনো ফাইলে যেকোনো সময় ক্লিক করলে** সম্পূর্ণ **"File URL & Hosting Hub"** ওপেন হবে।

- **সঠিক লিঙ্ক ফরম্যাট**:
  - **🌍 Public Live URL (Global Internet)**:
    ```
    https://[tunnel-subdomain].serveousercontent.com/ফোল্ডারের_নাম/ফাইলের_নাম.html
    ```

    *(উদাহরণ: `https://c22d485d77f63fa3-103-72-198-65.serveousercontent.com/myfolder/index.html`)*
  - **🏠 Local Wi-Fi (LAN) URL**:
    ```
    http://192.168.0.102:8080/ফোল্ডারের_নাম/ফাইলের_নাম.html
    ```

  - `📋 COPY PUBLIC LINK`: বন্ধুদের সাথে শেয়ার করার জন্য পাবলিক লিঙ্ক কপি।

  - `🌐 OPEN IN BROWSER`: ব্রাউজারে সরাসরি ফাইলটি রান করা।
  - `📱 QR CODE`: মোবাইল দিয়ে স্ক্যান করার জন্য কিউআর কোড।
  - `✏️ EDIT IN CODE EDITOR`: ইন-অ্যাপ কোড এডিটরে সরাসরি কোড এডিট ও সেভ করা।
  - `🚧 TOGGLE MAINTENANCE`: নির্দিষ্ট ফাইলের জন্য HTTP 503 Maintenance চালু বা বন্ধ করা।

## 📂 ফাইল ম্যানেজার ব্যবহারের নির্দেশিকা (How to Use File Manager)

1. অ্যাপের নিচে থাকা **Files** ট্যাবে যান।
2. নতুন ফাইল তৈরি করতে **📄 FILE** বা নতুন ফোল্ডার তৈরি করতে **📂 FOLDER** চাপুন।
3. ডিভাইস থেকে HTML/PHP/Images আপলোড করতে **⬆️ UPLOAD** চাপুন।
4. **যেকোনো ফাইলে ট্যাপ করুন** — তাৎক্ষণিকভাবে **File Link & Hosting Hub** পপ-আপ হবে।
5. **📋 COPY PUBLIC LINK** বাটনে চাপ দিয়ে পাবলিক লিঙ্ক কপি করুন এবং বন্ধুদের সাথে শেয়ার করুন!
