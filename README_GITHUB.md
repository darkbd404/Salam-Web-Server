# Salam Android Web Server - GitHub Ready

## Easiest Android-only workflow

1. Create a GitHub repository.
2. Upload the contents of this project, including `.github/workflows/build-apk.yml`.
3. Open the repository's **Actions** tab.
4. Select **Build APK**.
5. If needed, choose **Run workflow**.
6. Wait for the build to finish.
7. Open the completed workflow run.
8. Under **Artifacts**, download **Salam-Web-Server-APK**.
9. Extract the downloaded artifact and install `app-debug.apk` on Android.

The app is a basic embedded HTTP server. It does not provide Android root/system control.
